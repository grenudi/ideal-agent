# scripts/ - the executables

`ideal-agent` builds and runs the program; `agent-env` is the shell every session and job starts from
(`branch`, `land`, AGENT_NAME, AGENT_BUILD). The rest are checks run by hand or by patrol, each saying its use
in its first lines: clones-check, licence-check, route-check, start-weight, read-weight, who-lands, workarounds,
overlay-check, lab-agent-free; `install-tad.sh` installs tad.
